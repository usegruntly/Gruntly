# Notice

The `hidden/` folders in this directory hold copies of test files from the public repository
[pallets/click](https://github.com/pallets/click), taken from the commits named in each `task.yaml` (`source.fix`), and the
problem statements quote the maintainers' changelog entries from the same commits. They are used here only as benchmark
data. Click is licensed under the BSD 3-Clause License; its license text is in `LICENSE-click.txt` and applies to those files.
